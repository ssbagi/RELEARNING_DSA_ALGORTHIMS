# Circular Queue Array

This folder contains a circular queue implementation using a fixed-size array.

## Files
- `circular_queue.h` — queue declaration and API
- `circular_queue.cc` — implementation and demo program
- `Makefile` — build targets for release, debug, ASAN, and perf builds

## Build
```bash
make
```

## Run
```bash
make run
```

The program logs its activity to `circular_queue.log`.
